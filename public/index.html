Step-by-Step Google Sheets Setup Guide

1

Create your Google Sheet

Go to sheets.new to create a new spreadsheet. Name it "Brands & Comms Inventory".

Copy the Spreadsheet ID from your browser's address bar. For example, in https://docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms/edit, the bold part is the ID.

2

Create a Google Cloud Service Account

  1. Open the Google Cloud Console.
  2. Enable the Google Sheets API in APIs & Services > Library.
  3. Go to IAM & Admin > Service Accounts and click Create Service Account.
  4. Name it (e.g. inventory-manager) and create it.
  5. Click the service account > Keys tab > Add Key > Create new key > Choose JSON. A key file will download.
  6. Important: Copy the service account email (e.g. inventory-manager@project-id.iam.gserviceaccount.com), open your Google Sheet, click Share, and give this email Editor access!
3

Configure Environment Variables

Create a .env file in the project root with the following variables:

GOOGLE_SPREADSHEET_ID=your_spreadsheet_id_here
# Option A: Path to downloaded JSON key file
GOOGLE_APPLICATION_CREDENTIALS=/path/to/your/service-account-key.json

# OR Option B: Direct credentials (ideal for cloud hosting like Render/Heroku/Vercel)
GOOGLE_SERVICE_ACCOUNT_EMAIL=your-service-account@project.iam.gserviceaccount.com
GOOGLE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nMIIEvgIBA...your key here...\n-----END PRIVATE KEY-----\n"
4

Spreadsheet Structure Reference

The app automatically manages two tabs. You can click "Initialize Sheet Tabs & Headers" above, or verify the structure manually:

Tab 1: Items Item ID | Item Name | Category | Unit of Measure | Low-Stock Threshold | Status

Tab 2: Transactions Transaction ID | Date | Item ID | Transaction Type | Quantity | Recipient | Event/Reason | Notes | Timestamp
